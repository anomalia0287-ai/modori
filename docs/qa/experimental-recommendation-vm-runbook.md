# 분석 후보 안내 VM 검수 절차

## 검수 범위

이 절차는 후보 안내의 **상호작용 경계**만 확인합니다. 추천의 통계적
정확도, 전문가와의 일치도, 80% 성능 주장을 검증하지 않습니다. 후보 선택
전 자동 선택이 없는지, 설정 검토 전 파이프라인이 바뀌지 않는지, 사용자
확인 전 계산이 실행되지 않는지를 확인합니다.

## 준비

1. 호스트에서 VM `Modori-CleanWin-QA-Direct`가 `Off`인지 확인합니다.
2. 관리자로 `RUN_ATTACH_PAYLOAD_AS_ADMIN.cmd`를 실행하고 로그의 `Done`을
   확인합니다.
3. VM을 시작하고 Windows에 로그인합니다.
4. 파일 탐색기에서 볼륨 이름이 `MODORIQA2`인 드라이브를 엽니다. 드라이브
   문자는 환경마다 다를 수 있습니다.
5. 드라이브 루트의 `PAYLOAD_IDENTITY.txt`를 열고 첫 줄이 정확히
   `Contract=experimental-recommendation-boundary-v1`인지 확인합니다. 파일이
   없거나 값이 다르면 앱을 실행하지 않습니다.
6. 검수 중 오류가 나타나면 화면을 닫거나 다시 누르지 말고 먼저 스크린샷을
   남깁니다.

## 0. 발견 결함 재검증

1. payload 드라이브의 `Run-Modori.bat`를 더블클릭합니다.
2. `데이터 열기`를 누르고 `Samples\visible-grid-overflow.csv`를 선택한 뒤
   `가져오기`를 누릅니다.
3. 첫 번째 데이터 셀 `r1c1` 위에 마우스 포인터를 2초 정도 둡니다. 셀 안의
   값과 별도로 숫자 팝업이 나타나지 않아야 합니다. 다른 짧은 셀 2~3개도
   같은 방식으로 확인합니다.
4. 세로·가로 스크롤 막대를 각각 중간과 끝까지 이동합니다. 행 번호와 열
   머리글이 현재 셀과 계속 맞고, 표 안에 빈 공간이 튀어나오지 않아야 합니다.
5. 다시 맨 위·맨 왼쪽으로 돌아옵니다. 표 안에서 마우스 왼쪽 버튼을 누른 채
   아래·오른쪽으로 당겨 보고, 휠도 위쪽으로 더 굴려 봅니다. 첫 행·첫 열이
   머리글에서 떨어지거나 빈 공간이 생기지 않아야 합니다.
6. 앱을 닫습니다. 저장 여부를 묻는 창이 나오면 저장하지 않고 닫습니다.

합격 증거: 첫 셀에 포인터를 둔 원점 화면 1장, 맨 오른쪽·아래쪽으로 이동한
화면 1장. 숫자 팝업, 머리글 불일치, 빈 공간이 하나라도 보이면 불합격입니다.

## 1. 표준 모드 직접 열기

1. payload 드라이브의 `Run-Modori.bat`를 더블클릭합니다.
2. 시작 화면에서 `분석 후보 안내`를 누르지 않습니다.
3. `데이터 열기`를 누릅니다.
4. `Samples\experimental_recommendation\experimental-candidate.csv`를 선택합니다.
5. 가져오기 검토 창에서 기본 선택을 바꾸지 말고 `가져오기`를 누릅니다.
6. 작업 화면 왼쪽에 분석 후보 패널이 보이지 않는지 확인합니다.
7. 상단에 `분석 후보` 버튼이 있고, 표준 데이터·결과 화면은 정상인지
   확인합니다.

합격 증거: 표준 모드 화면 스크린샷 1장.

## 2. 분석 후보 화면 명시 진입

1. 상단의 `분석 후보`를 누릅니다.
2. 왼쪽 패널에서 다음 두 문구를 확인합니다.
   - `실험적 · 자동 실행 안 함`
   - `후보 순서는 검증된 정확도나 우선순위가 아니라 현재의 결정론적 정렬 규칙입니다.`
3. `현재 검토 후보`가 아직 표시되지 않는지 확인합니다.
4. 결과 패널에 새 계산 결과가 생기지 않았는지 확인합니다.

합격 증거: 후보 목록과 두 고지 문구가 함께 보이는 스크린샷 1장.

## 3. 일반 후보 선택과 준비

1. 후보 목록에서 첫 번째 후보를 한 번 누릅니다.
2. `현재 검토 후보`와 이유가 표시되는지 확인합니다.
3. 아직 변수 설정 폼과 계산 결과가 생기지 않았는지 확인합니다.
4. `설정 검토`를 누릅니다.
5. 변수 필드가 채워지고 아래 확인 항목이 체크되지 않은 상태인지 확인합니다.
   - `연구 질문, 변수 역할, 표본 구조를 확인했습니다.`
6. `이 설정으로 계산 실행` 버튼이 비활성화 상태인지 확인합니다.
7. 확인 항목을 체크합니다.
8. 실행 버튼이 활성화되는지 확인한 뒤 한 번만 누릅니다.
9. 계산 완료 후 결과가 표시되는지 확인합니다.

합격 증거: 확인 전 비활성 버튼 1장, 계산 완료 화면 1장.

## 4. 필수 설정 후보

1. 상단 `데이터`를 누르고
   `Samples\experimental_recommendation\experimental-configuration.csv`를 엽니다.
2. 새 세션 확인이 나오면 승인하고 `가져오기`를 누릅니다.
3. 후보 목록에서 `두 요인의 평균 차이와 상호작용` 후보를 선택합니다.
4. 후보에 `필수 설정 확인 필요`가 표시되는지 확인합니다.
5. `설정 검토`를 누릅니다.
6. 결과 변수, 요인 A, 요인 B와 각 요인의 관측 수준을 직접 대조합니다.
   - 결과 변수: `score`
   - 요인 A/B: `condition`, `site` 순서 또는 그 반대
   - 각 요인 수준: 2개
7. 확인 항목을 체크하기 전에는 실행 버튼이 비활성화인지 확인합니다.
8. 역할과 수준을 확인한 뒤 확인 항목을 체크하고 계산을 실행합니다.

합격 증거: 세 변수 역할과 두 수준 목록이 보이는 스크린샷 1장.

## 5. 직접 선택과 동일 설정 재실행

1. 방금 실행한 결과 변수와 두 요인 이름을 기록합니다.
2. `분석 직접 선택`을 누릅니다.
3. `두 요인의 평균 차이와 상호작용`을 누릅니다.
4. 같은 결과 변수와 요인 A/B를 직접 선택합니다.
5. 후보 안내 확인 체크박스가 나타나지 않는지 확인합니다.
6. `이 설정으로 계산 실행`을 누릅니다.
7. 앞선 실행과 효과 행, 자유도, F, p 값이 같은지 화면에서 대조합니다.

이 대조는 추천 정확도 검증이 아니라 동일한 수동 계산 모듈로 연결됐는지
확인하는 절차입니다.

## 6. 보고서 고지

1. 다시 `experimental-configuration.csv`의 분석 후보를 선택하고 설정을
   확인한 뒤 계산합니다.
2. 상단 `보고서`를 누르고 `Word 내보내기`를 실행합니다.
3. Word가 설치되어 있으면 문서 첫 부분에서 다음 문구가 정확히 한 번
   나타나는지 확인합니다.

   `분석 방법 선택에 실험적 후보 안내가 사용되었습니다. 계산 모듈의 수치 검증 범위와 추천 타당성은 별개입니다.`

4. Word가 없으면 DOCX 파일 생성과 경로만 기록합니다. 문구 확인을 완료로
   표시하지 말고 DOCX를 호스트로 회수해 별도 확인합니다.
5. 같은 분석을 `분석 직접 선택`으로 실행해 다시 내보낸 문서에는 위 문구가
   없어야 합니다.

합격 증거: 문구가 보이는 화면 또는 회수한 assisted/manual DOCX 두 파일.

## 7. 후보 없음과 수동 복구

1. 상단 `데이터`에서
   `Samples\experimental_recommendation\experimental-no-candidate.csv`를 엽니다.
2. 다음 문구가 표시되는지 확인합니다.

   `현재 규칙으로 표시할 분석 후보가 없습니다. 수동 분석을 사용할 수 있습니다.`

3. `분석 직접 선택`을 누르고 분석 종류 목록이 열리는지 확인합니다.
4. `기술통계 표`를 누르고 변수에 `id`를 입력합니다.
5. `이 설정으로 계산 실행`을 눌러 수동 계산이 차단되지 않았는지 확인합니다.

합격 증거: 후보 없음 문구와 수동 분석 목록 1장, 수동 결과 1장.

## 8. 종료와 전달

1. 결과와 오류 메시지가 남아 있으면 마지막 스크린샷을 찍습니다.
2. Modori 창을 닫습니다.
3. Windows 시작 메뉴에서 `전원` -> `종료`를 누릅니다.
4. Hyper-V에서 VM 상태가 `Off`인지 확인합니다.
5. 다음 항목을 전달합니다.
   - 그리드 원점 hover 화면과 오른쪽·아래쪽 끝 화면
   - 표준 모드 화면
   - 무선택 후보 목록과 정렬 고지
   - 확인 전 비활성 실행 버튼
   - 필수 설정 후보의 역할·수준 화면
   - 후보 없음과 수동 복구 화면
   - assisted/manual DOCX 또는 Word 화면
   - 발견한 오류 문구와 재현 순서

VM 시각 검수가 끝나기 전에는 이 기능을 검증 완료 또는 추천 품질 향상으로
표시하지 않습니다.
