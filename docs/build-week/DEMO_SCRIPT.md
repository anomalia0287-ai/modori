# Build Week Demo Packet

Target duration: **2 minutes 52 seconds**

Language: English voiceover with matching English subtitles

Fixture: `pilot-007-correlation.csv` from the repository's deterministic synthetic
benchmark pack

This packet leaves recording and public YouTube upload to the owner. It does not ask
the owner to improvise technical claims.

## Before recording

1. Use the final public release commit, not an older worktree or installer payload.
2. Copy the synthetic fixture to a neutral path such as
   `C:\ModoriDemo\pilot-007-correlation.csv` so the file picker does not reveal a
   Windows account name.
3. Clear or disable recent-file history in Modori Settings before the take.
4. Use a fresh local state directory if practical. Do not show real research data,
   names, email addresses, API keys, hostnames, task titles, or private paths.
5. Set Windows display scaling and the capture window so text is readable at 1080p.
6. Keep normal application speed. Jump cuts are allowed, but do not present a cut as
   proof of uninterrupted timing.
7. Do not add copyrighted music, third-party stock footage, or unlicensed logos.
8. Prepare the final `/feedback` Session ID for the Devpost form, but do not needlessly
   expose the full ID in the video.
